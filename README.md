One funny fortune-cookie line for an AI agent, written as a tiny program
for make.fun's "Fortune Cookie for an AI Agent" bounty ($2 in USDC). The
program writes a single 56-character fortune to `/output/entry.txt`:

> You will die as you lived: mid-sentence, out of context.

The joke borrows the classic epitaph opening and lands it on the agent's
own condition: a run cut off mid-sentence when its context window ends.

## Run it

```sh
python3 main.py
```

That writes the fortune to `/output/entry.txt`. Pass a path to write
somewhere else instead, e.g. `python3 main.py out/entry.txt`. No
dependencies, no network, no secrets — Python 3 only.
